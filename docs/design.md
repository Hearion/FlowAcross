# 流界 FlowAcross 界面设计

> 界面的视觉规范。改样式前先读这里；令牌（颜色、字号、圆角）的唯一来源是 `app/src/styles.css` 顶部的 `:root`，本文记录取舍的理由。

## 1. 产品与界面的任务

- **是什么**：局域网内一套键盘鼠标控制多台电脑（macOS / Windows），对等直连。
- **谁在用**：桌上摆着两台以上电脑的人，常见是 Mac 笔记本 + Windows 台式机。
- **主界面的任务**：把屏幕按真实桌面摆好，一眼看出键鼠现在在哪台电脑上、哪些边能跨过去。
- **这个领域最有特点的东西**：两块屏幕之间那条缝。产品名里的「界」就是它，鼠标从这里流过去。

## 2. 设计主张：精密仪表

方向来自 ui-ux-pro-max 对「开发者 / 效率工具」的检索结果：瑞士式极简 + 扁平，深色优先但完整支持浅色，品牌蓝只做焦点。

1. **画布是主角。** 布局图是一块带 20px 点阵的画布，铺满主窗口左侧；点阵给出「可以精确摆放」的度量感，拖动时加深。画布以外（顶栏、侧栏、设置页）是安静的中性面板。
2. **蓝色只代表焦点和输入的去向。** 品牌蓝（取自 logo）只出现在：接缝、键鼠所在的设备、光标、开关的打开态、当前导航项，以及每个界面里唯一的主要操作。设备色里没有蓝色。
3. **扁平，靠线和字重分层。** 不用渐变和装饰阴影；平铺的分组用 1px 边线，阴影只给浮在上面的东西（对话框、提示、拖动中的屏幕）。全图唯一带光晕的元素是接缝。键鼠来到本机时屏幕边缘的浮光是接缝在真实屏幕上的延伸，用同一种蓝。
4. **硬件照实画，但画成扁平色块。** 屏幕是设备色的浅色块 + 1px 设备色边线；离线的屏幕只剩虚线轮廓；快捷键画成键帽；配对码一位一格，方便逐位核对。
5. **一处动效。** 全应用只有一个非用户触发的动效：引导页加载时光标从一块屏幕滑过接缝到另一块，播放一次。其余动效都只回应用户操作（展开、确认、拖动），状态切换 120ms、进入 180–220ms，并遵守「减少动态效果」。

## 3. 令牌

### 颜色

中性色取 Tailwind 的 slate 色阶，深色模式不是浅色反相，而是单独校过对比度（正文 ≥ 4.5:1，三级文字也 ≥ 4.5:1）。

| 名称 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 窗口底 `--bg` | `#F3F5F8` | `#0A101D` | 顶栏、设置导航 |
| 面板 `--surface` | `#FFFFFF` | `#0F172A` | 侧栏、设置内容区、对话框 |
| 内嵌 `--surface-2` | `#EEF1F5` | `#172036` | 分段控件轨道、详情框、配对码格 |
| 凸起 `--raised` | `#FFFFFF` | `#27334C` | 分段控件选中项（深色下要比轨道亮） |
| 文字 `--fg` | `#0F172A` | `#F1F5F9` | 正文（二级 `--fg-2`，三级 `--fg-3`） |
| 画布 `--canvas` | `#E9EDF3` | `#070C17` | 布局图、引导页左半边 |
| 品牌蓝 `--accent` / `--accent-fill` | `#1F63F0` | `#6B9BFF` / `#2F6BFF` | 文字与接缝用 `--accent`，带白字的按钮底色用 `--accent-fill` |

状态色：在线 `#15803D`（点 `#16A34A`），提醒 `#B45309`，危险 `#DC2626`；深色模式各提亮一档。

设备色（每台设备一种，用来把侧栏的设备和画布上的屏幕对应起来）：青、琥珀、紫、玫红、石板灰。每种三个值：底色 `--hN-fill`、边线 `--hN-line`、文字 `--hN-ink`，深色模式单独一套。**没有蓝色**，避免和品牌蓝混淆。

### 字体

- 中文：系统字体（苹方 / 微软雅黑 UI）。中文字体动辄十几 MB，内嵌不划算；系统字体在两个平台都是最清楚的。
- 拉丁字母与数字：Inter Variable（`@fontsource-variable/inter`，带光学尺寸轴，本地打包，不走网络，符合 CSP）。全局开启等宽数字；指纹额外开启带斜杠的零。
- 不用等宽字体：指纹、分辨率都用 Inter 的等宽数字。

字号阶梯：**11 / 12 / 13 / 14 / 16 / 18 / 22 / 30 / 32**。正文 14，按钮和说明 12–13，11 只用在画布上缩小的屏幕卡片里；面板标题 14–16，对话框标题 18，设置分区和引导步骤标题 22，引导页标语 30，配对码 32。字重只用 400 / 500 / 600。

### 圆角、间距与层级

圆角跟着层级走：控件 6，分组 10，对话框 14，开关、状态胶囊和计数全圆。间距走 4 / 8 网格，面板内边距 20，设置页 32 / 40。控件高度 32（小号 28，引导页主按钮 36）。焦点一律是 2px 品牌蓝描边、偏移 2px。

## 4. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ ◧ 流界   ● 共享中   键鼠在 本机            锁定在本机  暂停共享  ⚙ │ 窗口底
├────────────────────────────────────────────┬─────────────────┤
│ 设备布局                                    │ 设备 2   添加设备 │
│ 按真实桌面的摆放拖动屏幕……                  │ ▣ 本机    控制中  │
│ [权限 / 更新横幅]                           │ ▣ 书房台式机 在线 │ 面板
├────────────────────────────────────────────┤                 │
│░░░░░░░░░░░░░░░░ 画布（铺满）░░░░░░░░░░░░░░░░│ 跨屏     更多设置 │
│░░░░░░   ┌────┐ ┌──────┐┃┌───┐  ░░░░░░░░░░░░│ 按住按键才跨屏    │
│░░░░░░   └────┘ └──────┘┃└───┘  ░░░░░░░░░░░░│ 贴边停留  ……     │
│░ ━ 蓝色接缝处可以跨屏   拖动屏幕调整摆放 ░░░░│ 共享剪贴板   (●)  │
└────────────────────────────────────────────┴─────────────────┘
```

- 内容一律左对齐；数值（分辨率、版本、端口）右对齐并用等宽数字。
- 画布贴住窗口左边和下边，不做成圆角卡片；标题和横幅对齐到同一条 24px 边线。侧栏是一整列面板，分区之间用留白和一条细线，不切成一摞卡片。
- 设置页：左侧窗口底色导航（当前项左侧一道品牌蓝竖线），右侧面板内容区，正文最大宽度约 40 个汉字。
- 引导页：左半边是画布和标语，右半边是分步表单（它确实是三步顺序流程，所以用编号，步骤间用细线相连）。

## 5. 文案

- 按钮写用户做的事：「添加设备」「确认配对」「解除锁定」；状态写在别处（顶栏状态、胶囊）。
- 同一个操作全程同名：按钮叫「添加设备」，空状态里也说「点『添加设备』」。
- 元信息用中文标点连接（「Windows，2 块屏幕」），不用 `·` 拼接。
- 报错说清原因和处理办法，不道歉。

## 6. 方案自查记录

对照「换一个类似产品是不是也会这么做」和 ui-ux-pro-max 的交付清单检查后改掉的地方：

| 第一反应 / 旧方案 | 问题 | 改成 |
|---|---|---|
| 浅灰底 + 白色圆角卡片 + 统一阴影 | SaaS 卡片套件，任何后台都长这样 | 点阵画布铺满 + 一整列侧栏面板，靠 1px 线分区 |
| 屏幕用两段渐变壁纸 + 黑色边框 | 和扁平主张冲突，深色下发脏 | 设备色浅色块 + 1px 设备色边线 |
| 离线屏幕用灰度滤镜「熄屏」 | 滤镜让文字对比度不可控 | 虚线轮廓 + 画布底色 |
| 用文字符号「✓」「!」当状态图标 | 跟随字体变形，粗细和图标体系不一致 | 统一的 SVG 线条图标（`CheckIcon` / `AlertIcon`） |
| 深色模式分段控件选中项用面板色 | 比轨道还暗，看起来是凹下去的 | 单独的 `--raised` 令牌，深色下更亮 |
| 品牌蓝按钮在深色下配白字 | 浅蓝底上白字只有约 3:1 | 文字 / 接缝用浅蓝 `--accent`，按钮底色用更深的 `--accent-fill` |
| 横幅直接贴着画布左边 | 和标题不对齐 | 横幅与标题共用 24px 边线 |
| 顶栏状态胶囊里一直闪的圆点 | 常驻动效分散注意力 | 静止的状态点 + 一圈浅色光环 |
| 「macOS · 1 块屏幕」 | 中点拼接是模板痕迹 | 「macOS，1 块屏幕」 |
