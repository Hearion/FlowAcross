# Download FlowAcross / 下载流界

FlowAcross lets you share one keyboard and mouse across Windows, macOS and Linux computers, with clipboard and file sharing between paired devices.

- [Latest stable release / 最新正式版](https://github.com/Hearion/FlowAcross-releases/releases/latest)
- [All releases, including previews / 全部版本和测试版](https://github.com/Hearion/FlowAcross-releases/releases)
- [Source code and build instructions / 源码与构建说明](https://github.com/Hearion/FlowAcross)

Windows uses an NSIS `.exe` installer; macOS uses `.dmg`; Linux provides `.deb`, `.AppImage` and Arch packages. Choose the package for your platform from the release page. Official download mirrors may use `dl.bapihou.com`, backed by Alibaba Cloud OSS. See the [privacy policy](../PRIVACY.md) for update/download requests and local-network behavior, and [uninstallation instructions](uninstall.md) for removal and data cleanup.
